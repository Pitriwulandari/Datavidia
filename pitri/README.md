## 1. Exploratory Data Analysis (EDA)

EDA telah dilakukan pada tabel utama `shipments` menggunakan Python, Pandas, Matplotlib, dan Seaborn.

Analisis mencakup pemeriksaan struktur dataset, tipe data, missing values, duplikasi, statistik deskriptif, distribusi target, distribusi fitur numerik dan kategorikal, korelasi, serta perbandingan karakteristik data train dan test.

Pemeriksaan duplikasi dilakukan dengan pendekatan berbasis ID dan pengambilan sampel untuk mengurangi penggunaan memori karena ukuran dataset cukup besar.

Hasil EDA digunakan sebagai dasar pengambilan keputusan pada tahap preprocessing dan modeling.
